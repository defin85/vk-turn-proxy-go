# Product Rules

## Primary workflow

- profile workflow
- managed-provider workflow

These are primary. Diagnostics and live work stay support-oriented and
secondary by default, even when the shell exposes them through explicit
routes or inspectors.

## Shell hierarchy

- compact shell bar
- primary body panes
- contextual inspector

## Do not regress to

- stacked library dashboard
- giant ready-state hero banner
- diagnostics as always-open peer column
- presets treated as top-level taxonomy
